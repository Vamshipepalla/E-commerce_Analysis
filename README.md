# 🛒 E-Commerce Data Analysis

> Turning order data into meaningful insights about sales, products, and customer behavior.

## 📌 About the Project

This project explores an e-commerce orders dataset using Python and Exploratory Data Analysis (EDA). The goal is to understand sales patterns, examine customer purchasing behavior, and explore differences across product categories, regions, payment methods, and customer ratings.

## 🎯 Project Objectives

- Clean and prepare the dataset for analysis.
- Explore sales trends and order patterns.
- Analyze product categories and regional performance.
- Examine payment methods and customer ratings.
- Use visualizations to identify patterns and relationships in the data.

## 🛠️ Tools & Technologies

| Technology | Purpose |
|---|---|
| Python | Data analysis |
| Pandas | Data cleaning and manipulation |
| NumPy | Numerical operations |
| Matplotlib | Data visualization |
| Seaborn | Statistical visualization |
| Jupyter Notebook | Interactive analysis |

## 🔍 Analysis Highlights

- **Sales Analysis:** Explore sales patterns and order trends.
- **Product Analysis:** Compare performance across product categories.
- **Regional Analysis:** Examine sales across different regions.
- **Payment Analysis:** Explore the distribution of payment methods.
- **Customer Ratings:** Analyze available ratings and their distribution.
- **Data Quality:** Handle missing values and duplicate records.

## 🚀 How to Run

**1. Clone the repository**

```bash
git clone https://github.com/Vamshipepalla/ecommerce-data-analysis.git
```

**2. Open the project folder**

```bash
cd ecommerce-data-analysis
```

**3. Install the required libraries**

```bash
pip install pandas numpy matplotlib seaborn jupyter
```

**4. Launch Jupyter Notebook**

```bash
jupyter notebook
```

Open `ecommerce.ipynb` and run the cells. Keep `ecommerce_orders.csv` in the same folder as the notebook.
